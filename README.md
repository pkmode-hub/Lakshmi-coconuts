# Lakshmi Coconuts website

A responsive static website for Lakshmi Coconuts, featuring:
- Whole mature coconuts for cooking, grating, coconut milk and oil extraction
- Three forms: with husk, semi-husked, fully dehusked
- Semi-husked and fully dehusked marked as speciality
- Indicative ₹25–₹30 price range and flexible supply averaging 500/day
- Direct farmer sourcing, Hyderabad/Telangana
- Contact links and Zepto vendor onboarding link
- Mobile navigation and responsive layout

## Files
- `index.html` — website content
- `styles.css` — responsive design
- `script.js` — mobile menu and current year
- `assets/` — cropped coconut photos supplied by the user

## Preview locally
Unzip the package, then open `index.html` in a browser. For a local development server, run from this folder:
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`.

## Publish online
This is not deployed yet. To publish:
1. Create a GitHub repository and upload all files/folders in this package.
2. In the repository, open **Settings → Pages**.
3. Select deployment from the `main` branch and `/ (root)` folder, then save.
4. GitHub Pages will provide a public URL after deployment completes.

Alternatives include Netlify Drop (upload the unzipped site folder) or any static hosting provider. Add a custom domain later if desired.

- Confirm whether the listed ₹25–₹30 price applies to all product forms or varies by form/grade.
